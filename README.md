# Формирование документов по шаблону (расширение для 1С:Бухгалтерии 3.0)

Добавляет в **Банк и касса → Платежные поручения** кнопку **«Сформировать документ»**. По ней платежка превращается в готовый документ Word по выбранному шаблону. Первый шаблон — **договор процентного займа**. Новые шаблоны добавляются из интерфейса 1С без программирования.

## Что где лежит

| Путь | Содержимое |
|---|---|
| `dist/ШаблоныДокументов.cfe` | **Готовое расширение для установки** |
| `docs/Инструкция по установке и развертыванию.md` | Для администратора: установка, клиент-серверный вариант, безопасный режим, права, обновление, удаление |
| `docs/Руководство пользователя.md` | Для бухгалтера: где кнопка, как сформировать, откуда берутся данные и куда подставляются |
| `docs/Инструкция по шаблонам.md` | Как сделать и загрузить свой шаблон Word |
| `docs/ТЗ и план.md` | Техническое задание, архитектура, план, статус |
| `src/extension/` | Исходный код расширения (модули и формы 1С) |
| `src/templates/` | Поставляемые шаблоны .docx и их описание |
| `Образцы/` | Исходный образец договора |
| `tools/` | Сборка (`build.py`), создание шаблона из образца (`make_loan_template.py`) |
| `tests/` | Интеграционные тесты на копии базы |
| `_dev/` | Копия тестовой базы, выгрузка конфигурации и логи для разработки. В поставку не входит, папку можно удалить. Исходная база `D:\1C\Base` не изменялась. |

## Быстрый старт

1. Сделайте резервную копию базы.
2. 1С → **Администрирование → Печатные формы, отчеты и обработки → Расширения → Добавить из файла** → `dist/ШаблоныДокументов.cfe`.
3. **Снимите флажок «Безопасный режим»** у расширения и перезапустите 1С.
4. **Банк и касса → Платежные поручения** → выделите платежку → **«Сформировать документ»**.

Подробнее — в `docs/Инструкция по установке и развертыванию.md` и `docs/Руководство пользователя.md`. Копии всех инструкций лежат в `dist/` вместе с расширением.
