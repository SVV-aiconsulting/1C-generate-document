# Руководство пользователя: формирование документов по шаблону

*Для бухгалтера. Как установить расширение, описано в «Инструкции по установке и развертыванию». Как сделать свой шаблон, описано в «Инструкции по шаблонам».*

---

## 1. Что умеет расширение

По **платёжному поручению** программа формирует готовый документ Word, например **договор процентного займа**. Реквизиты сторон, суммы, даты и подписи она подставляет сама. Вы только проверяете значения и при необходимости исправляете их.

---

## 2. Подготовка к работе: что заполнить в 1С

Расширение ничего не придумывает. Оно берёт данные из платёжного поручения и из карточек вашей организации и контрагента. Чем полнее заполнены карточки, тем меньше придётся дописывать вручную. Ниже перечислено, что нужно проверить **один раз** перед началом работы и затем поддерживать для каждого нового заёмщика.

Обозначения: **обязательно** — без этого договор будет неполным, поле подсветится красным; **желательно** — улучшает договор, но можно обойтись.

### 2.1. Карточка вашей организации (Заимодавец)

**Где:** Главное → Организации (или Справочники → Организации) → открыть организацию.

| Что заполнить | Где в карточке | Важность | Для чего в договоре |
|---|---|---|---|
| Сокращённое наименование, например ООО "Ромашка" | Поле «Сокращённое наименование» | **Обязательно** | Вводная часть и реквизиты |
| Полное наименование | Поле «Полное наименование» | Желательно | Поле для своих шаблонов |
| ИНН, КПП | Поля «ИНН», «КПП» | **Обязательно** | Реквизиты (обычно уже заполнены) |
| ОГРН | Поле «ОГРН» | **Обязательно** | Реквизиты |
| Юридический адрес (с городом) | Раздел «Адреса и телефоны» → «Юридический адрес» | **Обязательно** | Реквизиты; из него же берётся место заключения договора («г. Мурманск») |
| Фактический / почтовый адрес, телефон, e-mail | Раздел «Адреса и телефоны» | Желательно | Поля для своих шаблонов |
| Код по ОКПО | Раздел «Коды» | Желательно | Не обязателен |
| **Руководитель и его должность** | Ссылка **«Подписи»** (ответственные лица) → «Руководитель», «Должность». Укажите дату, с которой он действует | **Обязательно** | «в лице генерального директора …», подпись «М.П. Иванова» |
| Банковский счёт | Ссылка «Банковские счета» (номер, банк, БИК) | **Обязательно** | Р/счёт, банк, к/счёт, БИК |

### 2.2. Карточка руководителя организации (физическое лицо)

**Где:** Справочники (или «Зарплата и кадры») → Физические лица → руководитель. Можно открыть и из «Подписей» организации, щёлкнув по ФИО.

| Что заполнить | Важность | Для чего в договоре |
|---|---|---|
| Фамилия, Имя, Отчество **полностью** (не инициалы) | **Обязательно** | «в лице … Ивановой Марии Петровны», подпись «М.П. Иванова» |
| Пол | Желательно | Выбор «действующего» / «действующей». Если пол не указан, он определяется по отчеству |

### 2.3. Карточка контрагента (Заёмщик)

**Где:** Справочники → Контрагенты → открыть контрагента.

| Что заполнить | Где в карточке | Важность | Для чего в договоре |
|---|---|---|---|
| Вид контрагента: юридическое лицо / индивидуальный предприниматель | Поле «Вид» | **Обязательно** | Для ИП договор подписывает сам предприниматель, КПП не нужен |
| Наименование с формой собственности, например ООО "Лютик" | «Полное наименование» (краткое строится из него автоматически) | **Обязательно** | Вводная часть и реквизиты |
| ИНН, КПП (КПП — только у юрлиц) | Поля «ИНН», «КПП» | **Обязательно** | Реквизиты |
| ОГРН (у ИП — ОГРНИП) | Поле «ОГРН» | **Обязательно** | Реквизиты |
| Юридический адрес | Раздел «Адреса и телефоны» → «Юридический адрес» | **Обязательно** | «Юридический адрес: …» |
| Фактический адрес | Там же → «Фактический адрес» | Желательно | Строка «Фактический адрес: …». Если пусто, строка в договор не выводится |
| Код по ОКПО | Поле «Код по ОКПО» | Желательно | «ОКПО …». Если пусто, не выводится |
| **Руководитель (подписант) и его должность** | Раздел **«Контактные лица»** → «Создать»: **Фамилия, Имя, Отчество** — каждое в своё поле; **Должность** — например «Генеральный директор» или «Директор» | **Обязательно** для юрлиц | «в лице генерального директора Петрова Сергея Николаевича», подпись «С.Н. Петров» |
| Банковский счёт заёмщика | Ссылка «Банковские счета» | **Обязательно** | р/счёт, банк, город, к/счёт, БИК |

> **Как быстро заполнить карточку контрагента.** В карточке есть кнопка **«Заполнить по ИНН»**. Она работает через сервис «1С:Контрагент», для неё нужна подписка ИТС и подключённая Интернет-поддержка. Сервис подставляет наименование, КПП, ОГРН и юридический адрес из ЕГРЮЛ и обычно сам создаёт контактное лицо — руководителя с должностью. После этого проверьте, что в контактном лице Фамилия, Имя и Отчество разнесены по своим полям, а должность указана.

> **Почему руководитель контрагента — в «Контактных лицах».** В типовой карточке контрагента 1С:Бухгалтерии нет отдельного поля «Руководитель». Расширение ищет контактное лицо, в должности которого есть слова «директор», «руководитель» или «президент». Если таких несколько, выбирается основное контактное лицо и должность со словом «генеральный». Если руководитель сменился, исправьте контактное лицо: старое пометьте на удаление или смените ему должность.

### 2.4. Платёжное поручение

| Что проверить | Важность | Для чего |
|---|---|---|
| «Организация» и «Счёт организации» | **Обязательно** | Заимодавец и его банковские реквизиты |
| «Получатель» (контрагент) и «Счёт получателя» | **Обязательно** | Заёмщик и его банковские реквизиты |
| «Сумма» | **Обязательно** | Сумма займа числом и прописью |
| Дата | **Обязательно** | Дата и номер договора (ДД/ММ/ГГ), срок возврата (+1 год) |
| «Договор» | Не обязательно | Только запасной источник подписанта контрагента, если в карточке нет контактного лица-руководителя |

### 2.5. Как проверить готовность

Откройте любую платёжку по займу и нажмите **«Сформировать документ»**. Над таблицей появится итог, например «Требуют внимания: не заполнено — 2, проверить — 4».

* **Красные** строки — это пробелы в карточках. В колонке «Обратите внимание» написано, где именно их заполнить.
* Откройте карточку по ссылке **«Организация»** или **«Контрагент»** над таблицей, заполните недостающее, запишите карточку и нажмите **«Обновить данные»**.
* **Жёлтые** строки — это значения, которые нужно сверить глазами: автоматическое склонение ФИО, ставка и срок по умолчанию.

Когда красных строк не остаётся, карточки готовы. Для следующих договоров с этим контрагентом ничего дописывать не придётся.

## 3. Где кнопка

**Банк и касса → Платежные поручения.** Кнопка **«Сформировать документ»** находится:

* **в списке** платёжных поручений, на панели над списком рядом с кнопкой «Печать»;
* **в форме** открытого платёжного поручения, на верхней панели.

Если кнопки не видно, откройте меню **«Ещё»**. Её можно вынести на панель: **Ещё → Изменить форму**.

> Платёжное поручение должно быть записано. Для нового, ещё не записанного документа сначала нажмите «Записать».

## 4. Как сформировать документ: по шагам

1. Выделите платёжку в списке (или откройте её).
2. Нажмите **«Сформировать документ»**. Откроется окно **«Сформировать документ по шаблону»**.
3. В поле **«Документ (шаблон)»** выберите нужный документ, например «Договор процентного займа». Программа запоминает последний выбранный шаблон.
4. Проверьте таблицу полей (раздел 5). Если нужно, исправьте значения прямо в колонке **«Значение»**.
5. Нажмите:
   * **«Сформировать и открыть»**, чтобы документ сразу открылся в Word;
   * **«Сохранить в файл...»**, чтобы сохранить документ в выбранную папку.
6. Если в документе остались пустые поля, программа покажет сообщение со списком. Заполните их в таблице и сформируйте документ ещё раз.

Сформированный файл — обычный документ Word. Его можно дальше редактировать, печатать и отправлять. В 1С он не сохраняется. Чтобы прикрепить его к платёжке, воспользуйтесь кнопкой «Присоединённые файлы» (скрепка) в форме платёжного поручения.

## 5. Окно «Сформировать документ по шаблону»

| Элемент | Назначение |
|---|---|
| **Платежное поручение** | Документ, по которому формируется договор (только просмотр) |
| **Документ (шаблон)** | Выбор документа из списка шаблонов |
| **Шаблоны документов...** | Открывает список шаблонов: добавить новый или изменить существующий |
| Ссылки **«Организация»**, **«Контрагент»**, **«Договор»** | Открывают карточки, из которых берутся данные, чтобы дозаполнить их |
| **Обновить данные** | Перечитывает значения из платёжки и карточек (после того как вы что-то дозаполнили в 1С) |
| Таблица: колонка **«Поле»** | Что это за значение, например «Контрагент (получатель): ИНН» |
| Таблица: колонка **«Значение»** | Что попадёт в документ. Можно исправить |
| Таблица: колонка **«Откуда взято»** | Источник значения: платёжка, карточка организации или контрагента, настройки шаблона, ваше исправление |
| Таблица: колонка **«Обратите внимание»** | Почему поле выделено цветом и где заполнить данные в 1С |
| **Вернуть значение из программы** (над таблицей) | Отменяет ваше исправление в выделенной строке |
| Флажок **«Запомнить исправленные значения для следующих документов»** | См. раздел 7 |
| **Сформировать и открыть** / **Сохранить в файл...** / **Закрыть** | Кнопки внизу окна |

Строки, исправленные вручную, выделяются **жирным шрифтом**.

### 5.1. Цветовая подсветка: на что обратить внимание

При открытии окна программа сама выделяет цветом поля, которые стоит проверить. Причина указана в колонке **«Обратите внимание»**. Над таблицей выводится итог, например: *«Требуют внимания: не заполнено — 2, проверить — 5»*.

| Цвет | Что означает | Примеры |
|---|---|---|
| 🔴 **Красный** | Значение **не заполнено**: в 1С нет данных. Впишите значение, иначе в договоре будет пусто | ОГРН, юридический адрес, руководитель контрагента (должность и ФИО) |
| 🟡 **Жёлтый** | Значение заполнено, но его **нужно проверить** | • **значение по умолчанию**: в 1С данных нет, и подставлено значение из настроек шаблона (ставка 15,0 %, номер договора из даты платёжки)<br>• **склонено автоматически** («в лице генерального директора Иванова Ивана Ивановича»)<br>• поле **отмечено для проверки** в настройках шаблона. Для договора займа так отмечен срок возврата: его всегда стоит сверить |
| 🟢 **Зелёный** | Подставлено **ваше ранее исправленное** значение (см. раздел 7) | Исправленное однажды склонение ФИО директора контрагента |
| Без цвета | Значение взято из 1С и сомнений не вызывает. Или поле **необязательное** и пустое: в договор оно просто не попадёт | ИНН, КПП, расчётный счёт, сумма; пустые ОКПО, фактический адрес |

Когда вы исправляете выделенное значение, подсветка снимается, а в колонке «Обратите внимание» появляется пометка «Исправлено вручную». Кнопка «Вернуть значение из программы» возвращает и значение, и подсветку.

> Подсветка — подсказка, а не запрет. Документ можно сформировать и с выделенными полями.

## 6. Откуда берутся данные и куда они подставляются (договор процентного займа)

### 6.0. Общий принцип

1. **Платёжное поручение — первичный источник.** Из него берутся номер, дата и сумма, ИНН и КПП плательщика и получателя (ровно в том виде, в каком они ушли в банк), а также банковские счета сторон.
2. **По платёжке определяются стороны договора:**
   * **Заимодавец** — ваша **организация**, плательщик (поле «Организация» платёжки);
   * **Заёмщик** — **контрагент**, получатель (поле «Получатель» платёжки).
3. **Всё остальное берётся из карточек этих сторон в 1С:** наименование, ОГРН, ОКПО, адреса и руководитель.
   * У **организации** руководитель и его должность хранятся в карточке организации, в разделе **«Ответственные лица»**.
   * У **контрагента** в типовой карточке Бухгалтерии нет отдельного поля «Руководитель». Руководителя ведут в разделе **«Контактные лица»** карточки контрагента: Фамилия, Имя, Отчество и должность («Директор», «Генеральный директор»). Программа берёт контактное лицо с должностью, в которой есть «директор», «руководитель» или «президент». Если подходящих несколько, предпочтение получает основное контактное лицо и должность «генеральный».
4. **Условия нового договора** (номер, дата, ставка, срок) в 1С заранее нигде не хранятся: договор как раз и создаётся сейчас. Поэтому они рассчитываются по платёжке (номер и дата — из даты платёжки) или берутся из значений по умолчанию в настройках шаблона (ставка 15,0 %, срок + 1 год). Такие поля подсвечиваются жёлтым, чтобы вы их сверили.
5. **Карточка договора** — элемент справочника «Договоры», выбранный в поле «Договор» платёжки. Это не файл Word, а учётная запись в 1С. Она используется **только как запасной источник**: подписант контрагента берётся из неё, если в контактных лицах контрагента руководителя нет. Подписант организации — если не заполнены ответственные лица организации.

**Где это видно в окне.** В таблице полей есть колонка **«Откуда взято»**. В ней для каждого значения указан источник, например «Платежное поручение: ИНН получателя» или «Карточка контрагента: «Контактные лица» (Петров Сергей Николаевич, Генеральный директор)». Над таблицей есть ссылки **«Организация»**, **«Контрагент»** и **«Договор»**. Они открывают соответствующие карточки, чтобы дозаполнить недостающие данные. После этого нажмите **«Обновить данные»**, и значения перечитаются. Ваши ручные исправления в окне при этом сохраняются.

### 6.1. Шапка и условия договора

| Место в договоре | Поле в окне | Откуда берётся |
|---|---|---|
| «ДОГОВОР № **28/04/26**» | Номер договора | **Дата платёжного поручения** в виде ДД/ММ/ГГ (как в образце). Формат меняется в настройках шаблона |
| «**г. Мурманск**» (слева в строке под заголовком) | Место заключения договора | **Город из юридического адреса** вашей организации (карточка организации). Если город не распознан (например, посёлок), поле будет красным — впишите вручную, значение запомнится |
| «**28 апреля 2026 г.**» (справа в той же строке) | Дата договора | **Дата платёжного поручения** |
| п. 1.1 «на сумму **9 300 000 (девять миллионов триста тысяч) рублей 00 копеек**» | Сумма: числом и прописью | **Сумма платёжного поручения**. Прописью программа пишет сама |
| п. 1.2 «из расчёта **15,0 %** годовых» | Процентная ставка | **Значение по умолчанию** из настроек шаблона (15,0). Всегда подсвечивается для проверки |
| п. 2.1 «не позднее **28 апреля 2027 г.**» | Срок возврата займа | **Дата платёжки + 1 год** (настройка шаблона). Всегда подсвечивается для проверки |

### 6.2. Вводная часть («…в лице …, действующего на основании …»)

| Место в договоре | Поле в окне | Откуда берётся | Если пусто — где заполнить |
|---|---|---|---|
| «**ООО «Ромашка»**, в лице …» | Организация: краткое наименование | Карточка организации: сокращённое наименование, кавычки «ёлочками» | Справочники → Организации → карточка |
| «в лице **генерального директора** **Ивановой Марии Петровны**» | Организация: должность и ФИО руководителя в родительном падеже | Карточка организации → **«Ответственные лица»**: руководитель на дату платёжки. Склоняется автоматически, поэтому подсвечивается жёлтым | Карточка организации → «Ответственные лица» |
| «**действующего / действующей**» | Организация: «действующего» / «действующей» | По полу руководителя (карточка физического лица, иначе по отчеству) | — |
| «на основании **Устава**» | Основание полномочий | Стандартное значение «Устава». Для ИП — «листа записи ЕГРИП» | Можно исправить в таблице |
| «**ООО «Лютик»**, в лице …» | Контрагент: краткое наименование | Карточка контрагента. Если в кратком наименовании нет формы собственности, оно строится из полного («ОБЩЕСТВО С ОГРАНИЧЕННОЙ ОТВЕТСТВЕННОСТЬЮ "ЛЮТИК"» → «ООО «ЛЮТИК»»). Для ИП — «ИП Фамилия Имя Отчество» | Справочники → Контрагенты → карточка, «Полное наименование» |
| «в лице **генерального директора Петрова Сергея Николаевича**» | Контрагент: должность и ФИО руководителя в родительном падеже | Карточка контрагента → **«Контактные лица»**: лицо с должностью директора или руководителя. Запасной вариант — подписант контрагента в карточке договора из платёжки. Для ИП — сам предприниматель | Карточка контрагента → «Контактные лица»: добавить руководителя и указать должность |

### 6.3. Раздел 9 «Адреса и реквизиты сторон»

Раздел оформлен таблицей без рамок в две колонки: слева **Заимодавец**, справа **Заемщик**. В первой строке названия сторон, во второй реквизиты, в третьей должность и подпись руководителя. Таблица не отрывается от текста договора и не разрывается между страницами. Необязательные строки (ОКПО, фактический адрес) выводятся только если заполнены.

| Строка | Откуда берётся | Если пусто — где заполнить |
|---|---|---|
| Наименование (заглавными) | Как во вводной части | — |
| ИНН, КПП | **Платёжное поручение** (ИНН/КПП плательщика или получателя). Если в платёжке пусто — карточка | Карточка организации или контрагента |
| Юридический адрес (обязательно) / фактический адрес (необязательно) | Карточка: раздел «Адрес и телефон». Если фактический адрес не заполнен, строка «Фактический адрес:» в договор не выводится | Карточка → «Адрес и телефон» |
| Р/счёт, банк, город банка, к/счёт, БИК | **Счёт, выбранный в платёжке** («Счёт организации» или «Счёт получателя»), и его банк | Платёжка → банковский счёт |
| ОГРН | Карточка | Карточка → «ОГРН» (для ИП — «ОГРНИП») |
| ОКПО (необязательно) | Карточка. Если не заполнен, строка «ОКПО» в договор не выводится | Карточка → «Код по ОКПО» |
| Должность ____ И.О. Фамилия | Руководитель, как во вводной части, в именительном падеже | Как во вводной части |

> **Обязательные данные сторон:** наименование, ИНН, ОГРН, юридический адрес, должность и ФИО подписанта (плюс КПП у юридических лиц и банковские реквизиты из платёжки). **Необязательные:** ОКПО, фактический и почтовый адрес, телефон, e-mail — если они пусты, поле не подсвечивается красным, а в договоре не остаётся пустой подписи.
>
> **Совет.** Чтобы в договорах не было пропусков, достаточно один раз заполнить карточки:
> * **организации** — «Ответственные лица» (руководитель и должность), ОГРН, юридический адрес;
> * **каждого контрагента-заёмщика** — «Контактные лица» (руководитель с должностью), ОГРН, юридический адрес.
>
> Если чего-то не хватает, поле подсвечивается красным, а в колонке «Обратите внимание» написано, где именно в 1С его заполнить. Заполните, нажмите «Обновить данные», и значение подтянется.

## 7. Исправление и запоминание значений

* Любое значение в таблице можно исправить перед формированием. Исправление попадёт только в этот документ.
* Если стоит флажок **«Запомнить исправленные значения…»** (он стоит по умолчанию), программа запоминает исправления:
  * **реквизитов организации** — для всех следующих документов этой организации;
  * **реквизитов контрагента** — для всех следующих документов с этим контрагентом. Например, если вы исправили склонение ФИО директора, в следующий раз оно подставится правильно;
  * **параметров шаблона**, у которых в настройках шаблона стоит «Запоминать».
* **Не запоминаются** данные самого платежа (сумма, дата, номер) и номер, дата, ставка и срок договора: у каждого договора они свои.
* Исправление привязано к значению, которое было в 1С. Если данные в карточке изменятся (например, сменится руководитель или заполнят ОКПО), программа подставит новые данные из карточки, а старое исправление применяться не будет. Поэтому **главный источник — всегда карточка**, а исправление в окне только закрывает пробел.
* Чтобы «забыть» исправление, выделите строку, нажмите **«Вернуть значение из программы»** и сформируйте документ при установленном флажке запоминания. Запомненное значение удалится.
* Запомненные значения общие для всех пользователей базы.

## 8. Имя файла

Имя файла задаётся в настройках шаблона. Для договора займа оно такое: **«Договор займа № 28-04-26 ООО Лютик.docx»**. Символы, которые нельзя использовать в именах файлов (например «/»), заменяются на «-».

## 9. Шаблоны документов

Список шаблонов открывается ссылкой **«Шаблоны документов...»** в окне формирования. В карточке шаблона можно:

* **Загрузить из файла...** — загрузить новый или изменённый файл Word;
* **Открыть для редактирования** — открыть шаблон в Word. После сохранения и закрытия Word нажмите «Записать» в карточке;
* **Сохранить в файл...** — сохранить шаблон на компьютер;
* на закладке **«Параметры шаблона»** изменить значения по умолчанию, например ставку 15,0 % или срок займа «+1 год» (см. раздел 10);
* на закладке **«Доступные поля»** посмотреть все поля, которые можно вставить в шаблон.

Как подготовить свой шаблон, подробно описано в **«Инструкции по шаблонам»**.

## 10. Как изменить значения по умолчанию (например, срок займа)

Срок возврата займа по умолчанию равен **дате платёжки + 1 год**. Значение можно поменять в двух местах:

* **Для одного договора.** Исправьте поле «Срок возврата займа (не позднее)» прямо в таблице перед формированием.
* **Для всех следующих договоров** (настройка общая для всех пользователей):
  1. В окне формирования нажмите **«Шаблоны документов...»** и откройте **«Договор процентного займа»**.
  2. На закладке **«Параметры шаблона»** найдите строку **`Договор.ДатаВозврата`**.
  3. В колонке **«Значение по умолчанию»** стоит `{{Документ.Дата|+1Г}}`, то есть дата платёжки + 1 год. Замените **только `+1Г`**:
     * `+2Г` — 2 года, `+3Г` — 3 года;
     * `+6М` — 6 месяцев, `+18М` — полтора года;
     * `+90Д` — 90 дней.
  4. Нажмите **«Записать и закрыть»**.

Так же меняется ставка по умолчанию: строка `Договор.Ставка`, значение `15,0`, замените его на нужное число.

> Если в вашей практике для каждого займа в 1С заводится карточка договора с заполненными ставкой и сроком действия, значения по умолчанию можно брать оттуда. Например, для ставки: `{{Договор1С.ПроцентнаяСтавка|ЧДЦ=1}} || 15,0`, для срока: `{{Договор1С.СрокДействия}} || {{Документ.Дата|+1Г}}`. Тогда сначала берётся значение из карточки договора, а если там пусто — значение по умолчанию.

Флажок **«Выделять для проверки»** в той же таблице включает жёлтую подсветку параметра в окне формирования.

> Если удалить шаблон окончательно, он создастся заново из поставки со значениями по умолчанию (1 год, 15,0 %). Ваши настройки при этом пропадут.

## 11. Сообщения программы

| Сообщение | Что делать |
|---|---|
| «Выберите документ (шаблон), который нужно сформировать» | Выберите шаблон в поле «Документ (шаблон)» |
| «Документ сформирован, но не заполнены поля: …» | Заполните перечисленные поля в таблице и сформируйте документ ещё раз, либо допишите их в Word |
| «…подключено в безопасном режиме…» | Обратитесь к администратору 1С: нужно изменить настройку расширения |
| «В шаблоне … не загружен файл Word» | Откройте шаблон («Шаблоны документов...») и загрузите файл .docx |
| Документ не открывается | На компьютере нет программы для файлов .docx. Используйте «Сохранить в файл...» и откройте файл другой программой |
