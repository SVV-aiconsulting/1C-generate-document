# Установка и развертывание расширения «Формирование документов по шаблону»

*Для администратора 1С. Как работать с расширением, описано в документе «Руководство пользователя».*

Файл расширения: **`ШаблоныДокументов.cfe`** (папка `dist`).

**Версия поставки: от 05.10.2026.**

| Файл поставки | Назначение |
|---|---|
| `ШаблоныДокументов.cfe` | Расширение для установки в базу 1С. Шаблон договора займа уже внутри |
| `Шаблон - Договор процентного займа.docx` | Тот же шаблон отдельным файлом. Нужен, только если шаблон в базе меняли вручную и его надо обновить (раздел 9.2) или взять за основу для своего шаблона |
| `Инструкция по установке и развертыванию.md` | Для администратора (этот документ) |
| `Руководство пользователя.md` | Для бухгалтеров: подготовка карточек, работа с окном, источники данных |
| `Инструкция по шаблонам.md` | Как сделать и загрузить свой шаблон Word |

---

## 1. Как устроено решение

### 1.1. Расширение хранится в базе, а не на компьютерах

В 1С вся прикладная программа (сама «Бухгалтерия», её формы, кнопки и доработки) хранится в **информационной базе**. На компьютерах пользователей стоит только платформа 1С («оболочка»), она одинакова для любых программ 1С.

Поэтому расширение:
* устанавливается **один раз в каждую базу**, а не на каждый компьютер;
* после установки становится доступно всем пользователям базы на всех компьютерах;
* хранится **отдельно от типовой конфигурации**: конфигурация не снимается с поддержки, обновления БП ставятся как обычно;
* **не изменяет** существующие данные (платёжки, справочники, проводки), а только читает их;
* добавляет в базу две собственные таблицы: справочник шаблонов и регистр запомненных значений. При удалении расширения они удаляются вместе с ним.

### 1.2. Где что выполняется (клиент-серверный вариант)

```
 Компьютер пользователя               Сервер 1С                         Сервер СУБД
 ─────────────────────                ─────────────────────             ────────────
 1. Кнопка «Сформировать          →   2. Шаблон .docx берётся из базы ← База 1С
    документ», правка полей           3. Распаковка во временную папку
                                         сервера 1С, подстановка данных,
                                         упаковка, удаление временных файлов
 4. Файл приходит по сети,        ←      (Word НЕ используется)
    сохраняется во временную
    папку пользователя и
    открывается ЛОКАЛЬНЫМ Word
```

* **Word нужен только на компьютерах пользователей** и только для просмотра результата. Подойдут MS Word, LibreOffice, МойОфис и т. п.
* **На сервере 1С Word не нужен.** Файл .docx — это ZIP-архив с XML, его заполняют средства самой платформы.
* На сервере нужна только возможность создавать временные файлы в его временной папке.

### 1.3. Варианты размещения базы

| Вариант | Где формируется файл | Особенности |
|---|---|---|
| **Клиент-серверный** (сервер 1С + SQL/PostgreSQL) | На сервере 1С, во временной папке учётной записи службы сервера | См. раздел 5 |
| **Файловая база в сетевой папке** | На компьютере пользователя: в файловом режиме «серверная» часть 1С работает на нём | Достаточно снять безопасный режим |
| **Файловая база на этом же компьютере** | На этом компьютере | Проверено в разработке |
| **Терминальный сервер / RDP** | На сервере 1С; Word нужен на терминальном сервере | Документ открывается в сеансе RDP |
| **Веб-клиент** (база опубликована на веб-сервере) | На сервере 1С | Готовый файл скачивается браузером |
| **1С:Фреш / облако 1С** | — | Загрузка своих расширений там обычно ограничена, уточняйте у провайдера |

| Требование | Значение |
|---|---|
| Конфигурация | 1С:Бухгалтерия предприятия, редакция 3.0, **ПРОФ или КОРП**. В базовой версии раздела «Расширения» может не быть |

## 3. Подготовка

1. **Резервная копия базы:**
   * в 1С: **Администрирование → Обслуживание → Резервное копирование и восстановление**;
   * или в Конфигураторе: **Администрирование → Выгрузить информационную базу** (.dt);
   * для клиент-серверной базы также подойдёт резервная копия средствами СУБД.
2. **Рекомендуется сначала установить расширение на копию базы**, сформировать 2–3 договора и только потом ставить в рабочую базу (раздел 7).
3. Предупредите пользователей: после установки им нужно перезапустить 1С.

## 4. Установка

### 4.1. Из режима 1С:Предприятие (основной способ)

1. Скопируйте `ШаблоныДокументов.cfe` на свой компьютер.
2. Запустите 1С под администратором.
3. **Администрирование → Печатные формы, отчеты и обработки → Расширения**.
4. **«Добавить из файла...»** → на предупреждение о безопасности нажмите **«Продолжить»** → выберите `ШаблоныДокументов.cfe`.
5. В строке расширения **«Формирование документов по шаблону»** **снимите флажок «Безопасный режим»** и подтвердите действие (подробности в разделе 6). Флажок «Активно» должен стоять.
6. Перезапустите 1С. Если программа предложит перезапуск, согласитесь.

### 4.2. Через Конфигуратор (альтернативный способ)

1. Откройте базу в режиме **Конфигуратор** под администратором.
2. **Конфигурация → Расширения конфигурации → Действия → Добавить**, имя `ШаблоныДокументов`.
3. Выделите расширение → **Конфигурация → Загрузить конфигурацию из файла...** → `ШаблоныДокументов.cfe`.
4. В окне «Расширения конфигурации» снимите флажок **«Безопасный режим»** (или назначьте профиль безопасности, раздел 6.2). Флажок «Активно» должен стоять.
5. **Конфигурация → Обновить конфигурацию базы данных** (F7).

### 4.3. Проверка после установки

1. Под обычным пользователем откройте **Банк и касса → Платежные поручения**.
2. На панели над списком должна быть кнопка **«Сформировать документ»** (рядом с «Печать»). Если её нет на панели, проверьте меню **«Ещё»**.
3. Выделите платёжку → «Сформировать документ» → «Сформировать и открыть». Должен открыться договор в Word.

## 5. Особенности клиент-серверной установки

Расширение рассчитано на работу с удалённым сервером. Свои тесты я проводил на файловой базе, поэтому на клиент-серверной базе пройдите этот чек-лист на копии.

1. **Временная папка сервера 1С.** Файлы создаются во временной папке учётной записи, под которой работает служба «Агент сервера 1С:Предприятия» (обычно `USR1CV8`):
   * Windows: `C:\Users\USR1CV8\AppData\Local\Temp` (или `TEMP` этой учётной записи);
   * Linux: `/tmp` (или `TMPDIR` пользователя `usr1cv8`).

   У службы должны быть права на запись туда (по умолчанию есть). Файлы удаляются сразу после формирования, объём — десятки килобайт.
2. **Антивирус на сервере** не должен блокировать создание и распаковку .zip/.docx во временной папке службы 1С. Если формирование «висит» или выдаёт ошибку доступа, добавьте временную папку службы в исключения.
3. **Профили безопасности кластера.** Если в кластере 1С включены профили безопасности, вместо полного отключения безопасного режима можно назначить расширению профиль (раздел 6.2).
4. **Несколько рабочих серверов в кластере.** Каждый рабочий сервер использует свою временную папку. Дополнительная настройка не нужна, файл формируется и удаляется в рамках одного вызова.
5. **Компьютеры пользователей.** Достаточно платформы 1С и программы для открытия .docx. Расширение на компьютеры не устанавливается, при подключении к базе 1С загружает его сама.
6. **Первый запуск после установки.** Пользователям, у которых 1С была открыта во время установки, нужно перезапустить программу.

## 6. Безопасный режим: что это и как настроить

### 6.1. Зачем снимать флажок

**Безопасный режим** — ограничение, которое платформа 1С накладывает на код расширения, пока ему не доверяют. Он запрещает работу с файлами, внешними программами, COM-объектами и т. п. Запрет действует даже на временные файлы.

Наше расширение распаковывает и упаковывает файл Word (.docx, по сути ZIP-архив) во временной папке сервера, поэтому в безопасном режиме сформировать документ невозможно. Если флажок не снять, пользователь увидит сообщение:
*«Расширение «Формирование документов по шаблону» подключено в безопасном режиме, в котором невозможно сформировать файл Word…»*

Снимая флажок, администратор подтверждает доверие к расширению. Расширение **не обращается** к сети, почте, внешним программам и файлам пользователей, только к своей временной папке. Исходный код открыт и находится в папке проекта `src/extension`, его может проверить специалист 1С.

### 6.2. Альтернатива для клиент-серверной базы: профиль безопасности

Если политика компании не позволяет полностью отключать безопасный режим, используйте **профиль безопасности** кластера 1С:

1. Администратор кластера в **консоли администрирования серверов 1С** создаёт профиль безопасности, например `ШаблоныДокументов`. Права в нём ограничены: без полного доступа к файловой системе, COM, внешним компонентам и т. п.
2. В свойствах расширения (Конфигуратор → «Расширения конфигурации») в поле безопасного режима вместо флажка указывается **имя этого профиля**.
3. Формирование документа проверяется на копии базы.

> Этот вариант я не проверял. Работа с временными файлами при профиле безопасности зависит от версии платформы и настроек кластера. Если с профилем документ не формируется, в профиле нужно разрешить доступ к временному каталогу сервера (виртуальный каталог с правами чтения и записи). Настройку должен выполнять администратор сервера 1С.

## 7. Рекомендуемый порядок внедрения

1. Выгрузить рабочую базу в .dt и развернуть копию (на сервере — отдельной базой в кластере).
2. Установить расширение в копию (раздел 4), снять безопасный режим или назначить профиль (раздел 6).
3. Сформировать договоры по нескольким платёжкам: на ООО и на ИП, с договором в платёжке и без него. Сверить с образцом.
4. Проверить под **обычным пользователем**, не администратором: видна ли кнопка, формируется ли документ.
5. Установить расширение в рабочую базу и сообщить пользователям о необходимости перезапуска.

## 8. Права пользователей

Права на объекты расширения (кнопка, окно формирования, справочник шаблонов, запомненные значения) выдаются через типовую роль **«Базовые права БП»**. Она есть у всех пользователей Бухгалтерии, поэтому дополнительная настройка обычно не нужна.

Если в базе используются нестандартные профили групп доступа без этой роли, добавьте её в профиль пользователя: **Администрирование → Настройки пользователей и прав → Профили групп доступа**.

## 9. Обновление расширения (установка новой версии поверх старой)

Удалять старую версию **не нужно и нельзя**: при удалении расширения удаляются шаблоны и запомненные значения. Новая версия ставится поверх старой.

### 9.1. Порядок действий

1. **Резервная копия базы** (раздел 3).
2. Попросите пользователей выйти из 1С (или предупредите, что после обновления нужен перезапуск).
3. **Администрирование → Печатные формы, отчеты и обработки → Расширения**.
4. Выделите «Формирование документов по шаблону» → **«Обновить из файла...»** (в некоторых версиях: **Ещё → Обновить из файла**) → выберите новый `ШаблоныДокументов.cfe` → подтвердите предупреждение безопасности.
5. Проверьте, что у расширения **снят флажок «Безопасный режим»** (при обновлении он может включиться снова) и стоит флажок «Активно».
6. Перезапустите 1С: **все** пользователи должны закрыть и снова открыть программу.

Через Конфигуратор: **Конфигурация → Расширения конфигурации** → выделить `ШаблоныДокументов` → **Конфигурация → Загрузить конфигурацию из файла...** → новый `.cfe` → снять «Безопасный режим» → **Обновить конфигурацию базы данных** (F7).

### 9.2. Что происходит с шаблоном договора займа

Новая версия расширения содержит обновлённый шаблон «Договор процентного займа». Он заменяется в справочнике «Шаблоны документов» **автоматически** при первом открытии окна «Сформировать документ» после обновления. Условие: этот шаблон в базе не меняли вручную (не загружали другой файл и не правили параметры).

Если шаблон в базе меняли, программа его **не трогает**, чтобы не затереть ваши правки. Тогда обновите его вручную:

1. **Банк и касса → Платежные поручения** → любая платёжка → **«Сформировать документ»** → **«Шаблоны документов...»** → откройте «Договор процентного займа».
2. **«Загрузить из файла...»** → выберите файл `Шаблон - Договор процентного займа.docx` из папки поставки (`dist`).
3. На закладке «Параметры шаблона» нажмите **«Найти параметры в шаблоне»**. Для новых параметров укажите значения по умолчанию, например для `Договор.Место` (место заключения) — `{{Организация.Город}}`.
4. **«Записать и закрыть»**.

**Как проверить, что шаблон обновился:** сформируйте договор. В новой версии (от 05.10.2026) реквизиты сторон в разделе 9 стоят в две колонки (Заимодавец | Заемщик), а дата договора — в одной строке с местом заключения.

### 9.3. Что сохраняется при обновлении

* загруженные вами шаблоны других документов;
* запомненные исправления значений;
* настройки параметров изменённых вами шаблонов.

### 9.4. Изменения в версии от 05.10.2026

* Договор займа: место и дата заключения — в одной строке, дата не переносится. Место заключения берётся из юридического адреса организации-заимодавца (параметр «Место заключения договора», можно исправить, исправление запоминается).
* Раздел 9 «Адреса и реквизиты сторон» — таблица в две колонки без рамок: стороны, реквизиты, подписи. Раздел не отрывается от текста и не разрывается между страницами. У обеих сторон выводятся ИНН/КПП, ОГРН, юридический адрес, банковские реквизиты. Необязательные ОКПО и фактический адрес выводятся только если заполнены.
* Поставляемый шаблон обновляется автоматически, если его не меняли вручную.

**Обновление самой Бухгалтерии.** Расширение не мешает обновлению БП. После обновления 1С проверяет, совместимо ли расширение с новой версией. Если появится предупреждение о расширении, сообщите разработчику, обычно хватает пересборки.

---

## 10. Удаление

**Администрирование → Печатные формы, отчеты и обработки → Расширения** → выделить → **«Удалить»**.

Вместе с расширением удаляются шаблоны и запомненные значения. Если шаблоны понадобятся, перед удалением сохраните их в файлы: карточка шаблона → «Сохранить в файл...». Платёжки и другие данные бухгалтерии не затрагиваются.

## 11. Возможные проблемы (для администратора)

| Проблема | Причина и решение |
|---|---|
| Нет кнопки «Сформировать документ» | Расширение не активно или пользователь не перезапустил 1С. Проверьте флажок «Активно» в списке расширений. Посмотрите меню «Ещё» в списке платёжек. |
| «…подключено в безопасном режиме…» | Снимите флажок «Безопасный режим» или назначьте профиль (раздел 6) и перезапустите 1С. |
| «Недостаточно прав» | У пользователя нет роли «Базовые права БП» (раздел 8). |
| Ошибка доступа к файлу / временному каталогу (клиент-сервер) | У службы сервера 1С нет записи во временную папку, или файлы блокирует антивирус (раздел 5). |
| Файл не открывается на компьютере пользователя | Не установлена программа для .docx или не настроена ассоциация файлов. Можно воспользоваться кнопкой «Сохранить в файл...». |
| Нет раздела «Расширения» | Базовая версия БП или у пользователя нет полных прав. |
| После обновления БП предупреждение о расширении | Обратитесь к разработчику для пересборки расширения под новую версию. |
